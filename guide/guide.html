Manual de Usuario: Generador HTML

Cree documentos científicos elegantes sin escribir una sola línea de código.

Descripción general

Este manual de usuario proporciona instrucciones detalladas sobre cómo utilizar el generador HTML. Este generador permite crear documentos HTML desde una interfaz intuitiva, facilitando el diseño de páginas web para cada artículo científico sin necesidad de escribir código manualmente, lo que es ideal para principiantes y profesionales por igual. No se requiere experiencia previa en programación para utilizar esta herramienta. El generador HTML ofrece una variedad de plantillas y opciones de tipo de artículo para adaptarse a diferentes necesidades y estilos de diseño, además también incluye una función para previsualizar el documento antes de guardarlo.

Requisitos previos

Navegador moderno
Conexión a Internet
Documento PDF base

Damos por hecho que el usuario tiene acceso al documento PDF del artículo científico que desea publicar, ya que dicho documento pasó por revisiones previas y fué aceptada para la publicación a su revista científica. Este documento será utilizado como base para generar el HTML.

Uso del generador HTML

  • Acceso: Ingrese a la plataforma https://adancr1.github.io/GENERATOR-HTML/ desde su navegador.
  • Preparación: Abra su PDF en una pestaña paralela.
  • Metadatos del Artículo: Complete los campos de metadatos como Número de revista, Páginas, Fecha, ISSN, DOI y tipo de artículo.
  • Títulos: Ingrese el título del artículo tanto en español como en inglés (No es necesario seleccionarlas como cabeceras h1 o h2 ya que vienen por defecto).
  • Autores y afiliación: Ingrese los nombres de los autores y sus respectivas afiliaciones. También ingrese la fecha en la que se recibió el artículo para su publicación.

    Utilice las herramientas del toolbar para lo super índices 1, 2, 3, n , sub índices 1, 2, 3, n y cursivas I

  • Resumen: Ingrese el resumen del artículo en español y en inglés al igual que las Palabras claves usando la herramienta toolbar de lista *.
